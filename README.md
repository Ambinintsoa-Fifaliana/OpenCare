OpenCare - Digitalisation des servcices sanitaires

OpenCare est une application de gestion des services sanitaires (hopitaux,clinque, CSB...) développée en PHP et MySQL. Le projet a pour objectif de digitaliser plusieurs services d’un établissement de santé comme la gestion des consultations, des patients, du personnel et des dossiers médicaux.

Fonctionnalités
  Système d’authentification
  Gestion du personnel
  Gestion des rôles utilisateurs
  Enregistrement des patients
  Gestion des consultations médicales
  Consultations spécialisées :
    Consultation classique
    Hospitalisation
    Suivi de grossesse
    Consultation pédiatrique
    Visite médicale
  Gestion des sessions
  Sécurisation des mots de passe
  Technologies utilisées
    PHP
    MySQL
    HTML
    CSS
    JavaScript

  État actuel du projet
